# impartial game DP

[Problem](https://atcoder.jp/contests/dp/tasks/dp_k)
## Solution 
This is a classic impartial game DP problem. The most important observation is that the only thing that matters is the current number of stones in the pile. Since both players play optimally, we do not need to simulate all possible sequences of moves. Instead, for every possible number of stones, we determine whether the player whose turn it is can force a win from that position.

Let dp[i] denote whether a position with i stones remaining is winning or losing for the player whose turn it is. A state is called winning if there exists at least one move that sends the opponent to a losing state. A state is called losing if every legal move sends the opponent to a winning state. This idea comes from the standard game theory principle that a player wants to move to a position from which the opponent cannot win.

The base case is straightforward. When there are 0 stones, the current player cannot make any move, so he immediately loses. Therefore dp[0] = false, meaning that a pile of size zero is a losing position.

Now consider a pile containing i stones. For every move value a[j], if i >= a[j], then the player can remove a[j] stones and leave i - a[j] stones for the opponent. If any of those resulting states is losing, then the current player can move there and guarantee victory. In that case, dp[i] becomes winning. If every possible move leads to a winning state for the opponent, then the current player has no way to force a win, so dp[i] is losing.

Mathematically, the transition is:
dp[i] = true
if there exists a move x such that dp[i - x] == false
Otherwise:
dp[i] = false

We compute the states from small to large because dp[i] depends only on states with fewer stones. For each pile size from 1 to K, we check all allowed moves. If we find a move leading to a losing position, we immediately mark the current position as winning.

After filling the DP table, the answer is determined by dp[K]. If dp[K] is true, then the starting position is winning and Taro can force a victory, so we print "First". Otherwise, the starting position is losing and Jiro wins assuming optimal play, so we print "Second".

The complexity is O(N × K) because for each of the K pile sizes we try up to N possible moves. With N ≤ 100 and K ≤ 100000, this easily fits within the limits. This problem is one of the standard examples of game DP, where positions are classified as winning or losing based on the states that can be reached from them.

## Recursive code 
```cpp
#include <bits/stdc++.h>
using namespace std;

#ifndef ONLINE_JUDGE
#include "trace.cpp"
#else
#define dbg(...)
#endif

#define int long long

const int mx = 100000 + 12;

int n, k;
vector<int> v;
int dp[mx];

int yo(int stone) {

    if (stone == 0)
        return 0;

    if (dp[stone] != -1)
        return dp[stone];

    int ans = 0;

    for (int i = 0; i < n; i++) {

        if (stone >= v[i]) {

            int nxt = yo(stone - v[i]);

            if (nxt == 0) {
                ans = 1;
                break;
            }
        }
    }

    return dp[stone] = ans;
}

void solve() {

    cin >> n >> k;

    v.resize(n);

    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }

    memset(dp, -1, sizeof(dp));

    if (yo(k))
        cout << "First\n";
    else
        cout << "Second\n";
}

int32_t main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
}
```

## Iterative Code 
```cpp
#include <bits/stdc++.h>
using namespace std;

#ifndef ONLINE_JUDGE
#include "trace.cpp"
#else
#define dbg(...)
#endif

#define int long long

void solve() {

    int n, k;
    cin >> n >> k;

    vector<int> v(n);

    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }

    vector<int> dp(k + 1, 0);

    dp[0] = 0;

    for (int stone = 1; stone <= k; stone++) {

        for (int i = 0; i < n; i++) {

            if (stone >= v[i] &&
                dp[stone - v[i]] == 0) {

                dp[stone] = 1;
                break;
            }
        }
    }

    if (dp[k])
        cout << "First\n";
    else
        cout << "Second\n";
}

int32_t main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
}
```
